# Palette Journal

## 2024-05-24 - Neutral UI States over Error States
**Learning:** Using an explicit "error" indicator (like a red cross `✖`) to represent a neutral, unselected state in a multi-select menu creates visual noise and false alarms, causing unnecessary anxiety for users. Unselected states should be neutral.
**Action:** Created a neutral indicator (`○` `e_option`) specifically for unselected menu items to differentiate neutral states from true errors (`e_error`).
