## 2024-05-22 - Semantic Feedback Icons
**Learning:** Using 'Error' (Red X) for neutral states (unselected menu items) or positive states (idempotent skips) creates false alarm fatigue and anxiety.
**Action:** Use specific semantic feedback: `e_success` (Green Check) for verified states, `e_warning` (Yellow Alert) for non-critical alerts, and `e_option` (Neutral/White) for neutral UI elements.
