## 2024-05-24 - CLI Menu False Alarms
**Learning:** Repurposing an error state (like a red X) to denote an "unselected" item in an interactive list creates false alarms for users, making them think an operation failed when it was merely skipped.
**Action:** Created a neutral `e_option` visual state (a white circle) to clearly distinguish "unselected" items without triggering anxiety.
