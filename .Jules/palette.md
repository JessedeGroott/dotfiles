## 2025-02-12 - Reducing alarm fatigue in CLI output
**Learning:** Using red error icons (✖) for skipped files that are already up-to-date causes unnecessary alarm and visual noise ("alarm fatigue"). Users might interpret "Skipping" as a failure.
**Action:** Use green checkmarks (✔) for neutral skips ("same file") and yellow warning icons (⚠) for other skips (e.g., "destination newer"). This makes the output more scanable and reassuring.
