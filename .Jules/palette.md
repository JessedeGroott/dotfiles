

## 2024-05-15 - [UI Affordance]
**Learning:** Using error styles (like red cross icons) for non-error states (e.g., idempotent operations or skipped updates) creates false alarms for the user, degrading the UX.
**Action:** Use success markers (green checks) for idempotent operations and warning markers (yellow warnings) for skipped actions that aren't necessarily bad but require attention.
