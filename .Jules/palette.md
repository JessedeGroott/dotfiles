## 2026-02-24 - False Alarm Fatigue
**Learning:** Using error icons (red X) for neutral or benign states (like unselected menu items or idempotent file skips) creates visual noise and desensitizes users to actual errors.
**Action:** Use neutral indicators (circles, indentation) for unselected states and success/info indicators (checks, arrows) for benign skips. Reserve error icons for actual failures.
