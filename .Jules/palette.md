# Palette's Journal

## 2024-05-22 - Neutral State for Unselected Items
**Learning:** Using an error indicator (red '✖') for unselected items in a checklist creates false alarm and cognitive load, as users perceive it as a failure state rather than a choice.
**Action:** Use a neutral indicator (e.g., '○') for unselected or inactive states to clearly distinguish them from actual errors.
